# ربات سیگنال کریپتو

سیستمی که بازار فیوچرز را رصد می‌کند و در صورت وجود ستاپ معاملاتی، سیگنال را به تلگرام می‌فرستد.
کل پروژه با هزینه صفر اجرا می‌شود.

> **هشدار:** این ابزار توصیه سرمایه‌گذاری نیست. تا وقتی نتیجه بک‌تست و پیپر تریدینگ تأیید نشده،
> هیچ پولی وارد بازار نمی‌شود. معامله فیوچرز با اهرم می‌تواند کل سرمایه را از بین ببرد.

## نقشه راه

| مرحله | کار | وضعیت |
|---|---|---|
| ۱ | موتور داده — دریافت کندل از بایننس | ✅ انجام شد |
| ۲ | بک‌تست — سنجش استراتژی روی ۲ سال گذشته | ⏳ در جریان |
| ۳ | موتور سیگنال — فیلتر ریسک و ساخت پیام | ⏳ |
| ۴ | اتصال به تلگرام | ⏳ |
| ۵ | اجرای خودکار روی GitHub Actions + پیپر تریدینگ | ⏳ |

## اجرای مرحله ۱

نیازی به نصب هیچ کتابخانه‌ای نیست:

```bash
python data.py 4h 730
```

پارامترها: `فاصله زمانی` و `تعداد روز`. برای یک ارز خاص، اسمش را آخر اضافه کن:

```bash
python data.py 4h 730 BTCUSDT
```

خروجی در پوشه `data/` ذخیره می‌شود، به شکل `BTCUSDT_4h.csv`.

## قواعد انتخاب ارزها

برای اینکه بک‌تست گمراه‌کننده نشود، ارزها باید سه شرط داشته باشند:

1. قرارداد پرپچوال واقعی باشد (نه سهام توکنیزه‌شده یا کالا)
2. حداقل ۲ سال سابقه معامله داشته باشد
3. حجم معامله ۲۴ ساعته بالای ۵۰ میلیون دلار باشد

## چرا GitHub Actions؟

برای اینکه سیستم ۲۴ ساعته و بدون هزینه اجرا شود. مخزن عمومی است چون دقیقه‌های اجرا در مخزن
عمومی نامحدود است؛ در مخزن خصوصی سهمیه ماهانه ۲۰۰۰ دقیقه است که برای اجرای هر ۱۵ دقیقه کافی نیست.
هیچ کلید یا رمزی داخل کد نیست — همه در GitHub Secrets نگهداری می‌شوند.

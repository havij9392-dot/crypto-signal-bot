# ربات سیگنال کریپتو

سیستمی که بازار فیوچرز را رصد می‌کند و در صورت وجود ستاپ معاملاتی، سیگنال را به تلگرام می‌فرستد.
کل پروژه با هزینه صفر اجرا می‌شود.

> **هشدار:** این ابزار توصیه سرمایه‌گذاری نیست. تا وقتی بک‌تست و پیپر تریدینگ تأیید نشده،
> هیچ پولی وارد بازار نمی‌شود. معامله فیوچرز با اهرم می‌تواند کل سرمایه را از بین ببرد.

## استراتژی نهایی

از میان **۵۶ استراتژی** (شامل استراتژی‌های لیورمور، دنیس، وایکوف، مینروینی، اونیل، کانرز،
الدر، راشکه، دارواس، واینستین، آنتونیچی و بقیه) روی ۱۳۸ ارز و ۲ سال داده ۴ ساعته، یک برنده بیرون آمد:

**کراس EMA20/EMA50 روی ۴ ساعت + فیلتر EMA200 + تأیید رژیم بیت‌کوین**

| سنجه | مقدار |
|---|---|
| Profit Factor | ۱٫۲۷ |
| انتظار هر معامله | +۰٫۱۴۳R |
| out-of-sample | +۰٫۱۹۱R (بالاتر از in-sample) |
| ارزهای سودده | ۹۲ از ۱۳۸ |

خروج: حد ضرر ۲٫۵×ATR · حد سود ۳R · حداکثر ۱۰ روز.
نرخ سیگنال: حدود **۴ تا ۵ در روز**.

جزئیات کامل: `reports/strategy_winner.md` و `reports/strategy_sweep.csv`

## ربات تعاملی

ربات (`@zakaisignal_bot`) سرمایه را می‌پرسد و بعد از آن هر سیگنال با حجم، مارجین و اهرم
مخصوص همان سرمایه می‌آید.

| دستور | کار |
|---|---|
| `/start` | خوش‌آمد + دکمه‌های سرمایه |
| `/capital` | تعیین سرمایه (۵۰۰ / ۱۰۰۰ / ۲۰۰۰ / ۵۰۰۰ یا مقدار دلخواه) |
| `/risk 0.5` | ریسک هر معامله به درصد |
| `/equity 1250` | به‌روز کردن موجودی فعلی |
| `/status` | وضعیت حساب |
| `/help` | فهرست دستورها |

**فرمول سایز:**

```
ریسک دلاری = سرمایه × درصد ریسک
حجم پوزیشن  = ریسک دلاری ÷ فاصله حد ضرر
اهرم        = کمترین مقدار بین ۱۰ و ۸۰ ÷ فاصله حد ضرر
مارجین      = حجم پوزیشن ÷ اهرم
```

اهرم هرگز از فاصله لیکویید رد نمی‌شود، پس حد ضرر همیشه قبل از لیکویید می‌خورد.
ترمز افت هم فعال است: اگر حساب زیر ۷۵٪ اوجش بیاید، ریسک به یک‌چهارم کاهش پیدا می‌کند.

> پاسخ ربات ممکن است ۵ تا ۱۵ دقیقه طول بکشد، چون روی کرون رایگان GitHub اجرا می‌شود.

## اجرا

```bash
python scanner.py           # اسکن و نمایش
python scanner.py --send    # اسکن و ارسال به تلگرام
python bot.py 270           # شنیدن دستورهای تلگرام به مدت ۲۷۰ ثانیه
```

بازسازی تحقیقات:

```bash
python fetch4h.py 150 730   # دانلود ۲ سال داده ۴ ساعته
python sweep.py             # مسابقه ۵۶ استراتژی
python finalists.py         # تست پایداری
```
